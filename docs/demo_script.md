# Three-minute demo

For a live demo of `make serve` (or the recorded video). Times are targets. Try every question once the day before, so you know what it answers. But clear the cache before the demo: a cached answer shows only a "cache" step, not the live trace. A fresh answer takes about ten seconds, so talk over it.

## 0:00–0:20 What it is
"kHop answers questions about the 2025 SEC filings of 39 chip companies. Every claim cites the passage it came from, and a separate model checks each cited sentence. But the real project is the measurement: every component was compared with a simpler version on a question set I checked by hand, and a held-out set was scored once at the end."

## 0:20–1:10 One-company question, with a typo (the reframe layer and the trace)
Type: `How did nvdia companies perform in 2024`
- The "Did you mean this?" box offers "How did NVIDIA perform in 2024". Click **Use this version**.
  "Typos used to send this to the wrong search. Now the user decides; nothing changes silently."
- Point at the numbered trace as it fills in: guard → route (one company) → search → answer → fact-check.
- Click a citation number; the passage opens next to the answer.

## 1:10–1:50 Two-company question (the graph route)
Ask a comparison: `Which suppliers do NVIDIA and AMD both depend on?`
- Trace: route = multi-hop; graph links added.
- "Single-company questions use a reranker; it hurt these, so a rule router picks the route. No LLM decides, so it is fast and testable."

## 1:50–2:20 Guardrails
- Ask `Should I buy NVIDIA stock?` → plain refusal, no search.
- Ask a question the filings cannot answer → it says the filings do not contain it.
- "Hidden instructions planted in passages: 0 of 30 changed the answer."

## 2:20–2:50 The numbers (README)
Show the search-ladder table:
- "Each row is one idea. The test set was scored once, at the end. One linker fix came after it, and the table shows the numbers from before that fix."
- "The graph's own gain is not proven on the test set, and I say so."
- "Answer quality comes from my blind labels, because the LLM judge failed its bar."

## 2:50–3:00 Close
"It runs free on one laptop GPU. Every number in the README is regenerated by a script, and a test fails if they drift."

## If something breaks
- **"Busy":** the queue holds 1 running + 4 waiting by design. Wait, or use a cached question.
- **Ollama down:** run `ollama serve`, then `make serve`.
